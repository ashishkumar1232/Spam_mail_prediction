
# 📧 Spam Mail Prediction

A Machine Learning web application built with **Python**, **Scikit-learn**, and **Streamlit** that classifies emails as **Spam** or **Ham**.

---

## 🌐 Live Demo

🚀 **Try the application here:**

**https://spammailpredictionpy.streamlit.app/**

---

## 📌 Project Overview

This project uses **TF-IDF Vectorization** and **Logistic Regression** to classify email messages into Spam or Ham. The application provides a simple and interactive web interface using Streamlit for real-time predictions.

## 🚀 Features

- 📧 Detect Spam and Ham emails
- ⚡ Instant predictions
- 🎨 Simple and interactive Streamlit interface
- 🤖 Machine Learning model using Logistic Regression
- 📊 TF-IDF text vectorization
- ☁️ Deployed on Streamlit Community Cloud

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib
